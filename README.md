# 狼人杀 · 法官计时器（离线单文件）

给法官用的发言计时器：**选版型 → 自动排座位 → 分阶段倒计时 → 到时提醒**。数据全部内嵌在 `index.html` 里，无后端、无 CDN、无联网请求，双击文件就能离线使用。

在线使用：https://wangzixiao-wzx.github.io/werewolf-judge-timer/

## 功能

- **选版型**：内嵌 106 个版型，可按板名 / 身份名 / 分类搜索、按 6 / 9 / 10 / 12 人筛选，也可 🎲 随机抽板。选中后自动按座位数重建座位表，并显示身份构成、板子说明与场次。
- **法官提醒**：从该板的规则里自动挑出发言、警徽、退水、遗言、自爆、屠边、投票等相关条目，开局前一眼看清特殊流程（例如「双爆吞警徽」「傀儡技能失效」）。
- **分阶段计时**：警上发言 / 警下发言 / 放逐发言 / PK / 遗言 / 自由发言，六个阶段各有独立时长（默认 120 / 120 / 120 / 60 / 60 / 120 秒，可逐项改）。
- **座位表**：点座位切人、点绿点标记出局 / 复活（「下一位」自动跳过出局者）、直接输入玩家名、记录每人本局累计发言用时与已发言标记。
- **🏷 玩家状态标记**：点座位卡上的 `＋ 标记` 打开面板，给每个玩家打多个状态标签。内置 4 组常用标签（警徽 / 竞选、信息 / 查验、夜间 / 技能、局势 / 备注，如警长、金水、查杀、抗推、被救、疑似狼、自爆），也可自定义标签并长期记住；还能「记一笔」自由备注。座位卡直接显示前两个标记 + 数量。
- **🕘 状态历史时间线**：所有标记增删、出局 / 复活、切换天数 / 昼夜 / 发言阶段、换版型、现场备注都自动留痕，每条带时刻、第 N 天、昼夜、阶段、版型、座位与玩家名。支持按类型 / 当前座位 / 关键词筛选，**撤销**标记或出局变更（回滚当前状态并追加一条撤销记录）、复制文本、导出 CSV、`新开一局`、单独清空历史。面板内也有「该玩家最近状态」。历史最多保留 800 条，防止 localStorage 膨胀。
- **到时提醒**：大号倒计时 + 进度环 + 三声提示音 + 震动 + 红色闪烁 + 标签页标题闪烁；不会自动抢跳下一位，由法官掌控。
- **天数 / 昼夜**：第 N 天、白天 / 夜晚手动切换，并自动写入历史作为时间锚点。
- **快捷键**：`空格` 开始/暂停 · `←` `→` 切人 · `R` 重置 · `+` `−` 加减 10 秒 · `T` 标记当前玩家 · `H` 状态历史 · `F` 全屏 · `M` 静音 · `1`–`9` 直接选座。
- **本机记忆**：版型、时长、座位名、出局状态、状态标记、历史时间线、自定义标签、累计用时、明暗主题都存在浏览器 `localStorage`，刷新不丢。「清空本局记录」会保留历史留档，可在历史面板单独清空或导出。
- **明暗主题 / 手机适配**：深色默认（夜间面杀护眼），可切浅色；窄屏自动改单列与大按钮。

## 离线怎么用

- **最简单**：把 `index.html` 单独下载 / 复制到任何电脑或手机，用浏览器打开即可，不需要其它文件、不需要网络。
- **在线版**：GitHub Pages 首次打开后由 Service Worker 缓存，之后断网也能打开；在浏览器菜单里「添加到主屏幕 / 安装应用」可当独立 App 用。
- 页面不会上传任何数据：玩家名、状态标记与历史都只存在本机浏览器，仓库与页面都不含对局记录、玩家昵称或战绩。导出的 CSV 由你主动下载，不会自动发送。

## 数据与隐私

版型数据来自本地 `werewolf.db` 的 `board / board_role / board_rule / role / faction` 配置表，经 `werewolf-boards/export_boards.py` 导出为脱敏快照后内嵌；**只包含板子配置、身份构成与规则文本**，不含对局记录、玩家昵称、对局文件名、法官署名、日期与任何内部字段名。各家村规可能不同，实际开局以主持人口径为准。

## 版型更新后重新生成

```bash
cd ../werewolf-boards && python export_boards.py
cd ../werewolf-judge-timer && python build_timer.py
```

`build_timer.py` 会校验板子数 / 规则数、检查内部字段与外链、把数据内嵌进模板并写出 `index.html`。仓库里保留 `index.template.html` 作为可维护源码，`index.html` 是生成产物，请勿直接手改产物。

发布（复用版型库的 REST API 发布脚本，避免代理下 git push 卡住）：

```bash
GITHUB_TOKEN=<PAT> python ../werewolf-boards/publish_github.py \
  --dir ../werewolf-judge-timer --repo werewolf-judge-timer
```

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | **单文件成品**，全部 HTML/CSS/JS/数据内嵌，可独立离线使用 |
| `index.template.html` | 页面源码模板（含 `/*__TIMER_DATA__*/` 占位） |
| `build_timer.py` | 从版型库快照生成 `index.html` |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | Pages 上的离线缓存与「安装到主屏幕」增强，单文件模式下可缺失 |
| `.nojekyll` | 让 GitHub Pages 跳过 Jekyll |

自测：在线版或本地版 URL 后加 `?selftest=1`，页面顶部会显示逐项断言结果（49 项，覆盖计时、版型、座位、状态标记、历史、撤销、导出、离线与窄屏布局）。
